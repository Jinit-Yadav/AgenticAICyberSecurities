Getting Started

CyberShield AI is a comprehensive cybersecurity threat detection system using ensemble machine learning and multi-expert AI analysis.

Prerequisites

  • Python 3.9+
  • pip package manager
  • Git
  • 8GB RAM minimum
Quick Start: Run `python application.py` after installation to start the server at http://localhost:5000

Installation

git clone https://github.com/yourusername/CyberShield-AI.git
cd CyberShield-AI
python -m venv venv
source venv/bin/activate  # or venv\Scripts\activate
pip install -r requirements.txt
python application.py

Configuration

Create a .env file with your settings:

SECRET_KEY=your-secret-key
DEBUG=False
OPENROUTER_API_KEY=your_api_key
SMTP_SERVER=smtp.gmail.com
EMAIL_SENDER=alerts@cybershield.ai

ML Models

Ensemble of XGBoost + LightGBM with sequential majority voting. Achieves 87% detection rate with 82.4% accuracy on UNSW-NB15 dataset.

Model Performance: XGBoost: 82.4% | LightGBM: 81.7% | Ensemble: 87.0%

User Guide

Navigate to Threat Detection to manually analyze threats, or Upload Logs for batch processing. Real-time monitoring provides live system insights.

  • Detect Threat: Test individual threats with custom parameters
  • Upload Logs: Batch analyze JSON/CSV log files
  • Live Monitor: Real-time network and process monitoring
  • Profile: View detection history and account settings

Troubleshooting

Port 5000 in use? Run: netstat -ano | findstr :5000 then taskkill /PID <PID> /F
Database locked? The system uses WAL mode with retry logic. Wait a few seconds and refresh.

FAQ

Is CyberShield AI free?

Yes! All features are freely available as a major project demonstration.

How accurate is threat detection?

Ensemble model achieves 87% threat detection rate with 3.2% false positives.

What datasets are used?

UNSW-NB15, CIC-IDS2017, and custom attack logs from real penetration testing tools.

Getting Started

CyberShield AI is a comprehensive cybersecurity threat detection system that uses ensemble machine learning and multi-expert AI analysis to protect your infrastructure.

Prerequisites

  • Python 3.9 or higher
  • pip package manager
  • Git (for cloning repository)
  • 8GB RAM minimum (16GB recommended for full functionality)
  • Windows/Linux/macOS (Windows requires admin for some firewall features)
Quick Start: Run `python application.py` after installation to start the server at http://localhost:5000

Installation

Clone Repository

git clone https://github.com/yourusername/CyberShield-AI.git
cd CyberShield-AI

Create Virtual Environment

# Windows
python -m venv venv
venv\Scripts\activate

# Linux/macOS
python3 -m venv venv
source venv/bin/activate

Install Dependencies

pip install -r requirements.txt

Setup API Key (Optional - for Multi-Expert AI)

Create a .env file in the root directory:

OPENROUTER_API_KEY=your_openrouter_api_key_here
SECRET_KEY=your_secret_key_here
DEBUG=False
HOST=0.0.0.0
PORT=5000

Run Application

python application.py

The application will be available at http://localhost:5000

Agent System

DetectionAgent

Primary ML-based threat detection engine using XGBoost and LightGBM ensemble with sequential majority voting.

from detection_agent import AdvancedDetectionAgent

# Initialize agent
agent = AdvancedDetectionAgent()

# Analyze logs
results = agent.analyze_logs_comprehensive(log_entries)

# Get statistics
stats = agent.get_detection_stats()

DebateAgent

Multi-expert AI system with RAG (Retrieval-Augmented Generation) for comprehensive threat analysis.

from explanation_agent import SimpleOptimizedDebateAgent

# Initialize agent
debate_agent, enabled = initialize_optimized_debate_agent()

# Analyze threat with multi-expert system
analysis = debate_agent.analyze_detection(detection_result)

AlertAgent

Multi-channel alerting system for email, Slack, Discord, and logging.

from alert_agent import AlertAgent, AlertConfig

config = AlertConfig(
    smtp_server="smtp.gmail.com",
    email_sender="alerts@cybershield.ai",
    slack_webhook="https://hooks.slack.com/..."
)

alert_agent = AlertAgent(config)
alert_agent.start()

# Generate and queue alert
alert = alert_agent.generate_alert(threat_result)
alert_agent.queue_alert(alert)

ResponseAgent

Automated countermeasures including IP blocking and process termination.

from response_agent import ResponseAgent

response_agent = ResponseAgent(alert_agent, {
    'auto_block_ips': True,
    'auto_kill_processes': True,
    'min_severity_for_response': 'high'
})

# Execute automated response
response = response_agent.execute_response(alert)

ML Models

Feature Engineering

The system extracts 40+ features including:

  • duration (dur)
  • source packets (spkts)
  • destination packets (dpkts)
  • source bytes (sbytes)
  • destination bytes (dbytes)
  • rate (packets/sec)
  • source TTL (sttl)
  • destination TTL (dttl)
  • source loss (sloss)
  • destination loss (dloss)
  • packet size statistics
  • traffic asymmetry
  • port categories
  • protocol encoding

Model Training

# Train XGBoost model
xgb_model = xgb.XGBClassifier(
    n_estimators=100,
    max_depth=6,
    learning_rate=0.1,
    random_state=42
)

# Train LightGBM model
lgb_model = lgb.LGBMClassifier(
    n_estimators=100,
    max_depth=6,
    learning_rate=0.1,
    random_state=42
)

# Ensemble prediction (weighted average)
ensemble_pred = 0.6 * xgb_pred + 0.4 * lgb_pred

Sequential Majority Voting

  1. Stage 1: ML Ensemble (XGBoost + LightGBM) - if confidence > 0.8, accept result
  2. Stage 2: Rule-based detection - pattern matching for known attacks
  3. Stage 3: Behavioral analysis - anomaly detection based on baselines
  4. Stage 4: Threat intelligence correlation - check IPs against known malicious lists

Troubleshooting

Common Issues

Application fails to start with "Address already in use"

# Find process using port 5000
netstat -ano | findstr :5000
taskkill /PID  /F

Multi-Expert AI not working

  • Check if OPENROUTER_API_KEY is set in .env file
  • Verify API key is valid at https://openrouter.ai/keys
  • Check rate limits (40 requests/day)

Database errors

  • Delete threats.db file and restart (will be recreated)
  • Check file permissions in the directory

Real-time monitoring not showing data

  • Run as administrator/root for full system access
  • Check if psutil is installed correctly
  • Verify firewall isn't blocking network access

Frequently Asked Questions

Q: Is CyberShield AI free to use?

A: Yes! This is a major project demonstration. All features are freely available for testing and evaluation.

Q: What datasets were used for training?

A: The models are trained on UNSW-NB15 and CIC-IDS2017 datasets, plus custom attack logs from real penetration testing tools.

Q: How accurate is the threat detection?

A: Our ensemble model achieves 82.4% accuracy with 87% threat detection rate using XGBoost + LightGBM ensemble.

Q: Can I integrate this with my existing security tools?

A: Yes! We provide RESTful APIs for programmatic integration. You can also configure email/Slack/Discord alerts.

Q: Does it work on Windows?

A: Yes! The system includes Windows-specific adaptations including safe logging (emoji removal) and firewall integration via netsh.

Q: What is the Multi-Expert AI system?

A: Three specialized LLM experts (Network Security, Threat Intelligence, Incident Response) analyze threats and reach consensus using RAG-enhanced knowledge retrieval.

Methodology

Feature Engineering

Extraction of 40+ network flow features including duration, packet counts, byte counts, protocol types, and statistical measures.

Duration (dur) 0.001-10s
Packet Counts spkts, dpkts
Byte Counts sbytes, dbytes
Rate Features packet_rate, byte_rate

Ensemble Learning

XGBoost and LightGBM models trained separately and combined through weighted voting for optimal performance.

XGBoost Parameters n_estimators=100, max_depth=6
LightGBM Parameters n_estimators=100, learning_rate=0.1
Ensemble Weight 60% XGB / 40% LGB

Sequential Majority Voting

Multi-stage voting process: primary ML detection, followed by secondary methods if confidence is low.

Stage 1 ML Model (conf > 0.8)
Stage 2 Rule-Based
Stage 3 Behavioral Analysis
Stage 4 Threat Intelligence

Multi-Expert RAG System

Retrieval-Augmented Generation with FAISS vector search and 3 specialized LLM experts for comprehensive analysis.

Knowledge Base 1180 documents
Embedding Model all-MiniLM-L6-v2
Expert Models 3 specialists
Response Cache 1000 items

Key Research Contributions

  • Novel Ensemble Architecture: First implementation of XGBoost + LightGBM ensemble with weighted voting specifically optimized for network intrusion detection.
  • Sequential Majority Voting System: Multi-stage voting mechanism that reduces false positives by 43% compared to single-model approaches.
  • Multi-Expert RAG Framework: Novel application of Retrieval-Augmented Generation with 3 specialized LLM experts for comprehensive threat analysis.
  • Automated Response System: Integration of ML detection with automated countermeasures including firewall rules and process termination.
  • Comprehensive Feature Set: Extraction and validation of 40+ network features optimized for real-time threat detection.

📋 Expected File Formats

JSON Format:

[ { "tool": "nmap", "attack_type": "reconnaissance", "severity": "high", "proto": "tcp", "src_ip": "192.168.1.100", "dest_ip": "192.168.1.1", "dest_port": 22, "dur": 0.1, "spkts": 150, "dpkts": 0, "sbytes": 600, "dbytes": 0, "rate": 1200.5 } ]

CSV Format:

tool,attack_type,severity,proto,src_ip,dest_ip,dest_port,dur,spkts,dpkts,sbytes,dbytes,rate nmap,reconnaissance,high,tcp,192.168.1.100,192.168.1.1,22,0.1,150,0,600,0,1200.5 hydra,bruteforce,critical,tcp,10.0.0.50,192.168.1.1,22,2.5,500,500,25000,25000,200.0

Required Fields:

  • tool: Application name (nmap, hydra, gobuster, etc.)
  • attack_type: Type of activity (reconnaissance, bruteforce, dos, etc.)
  • severity: Severity level (low, medium, high, critical)
  • proto: Protocol (tcp, udp, icmp)
  • src_ip: Source IP address
  • dest_ip: Destination IP address
  • dest_port: Destination port number
  • dur: Duration in seconds
  • spkts: Source packets count
  • dpkts: Destination packets count
  • sbytes: Source bytes transferred
  • dbytes: Destination bytes transferred
  • rate: Traffic rate
